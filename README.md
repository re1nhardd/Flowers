# flowers

Мобильное веб-приложение: определение растения по фото через OpenAI и персональный гайд по уходу.

## Запуск

Откройте start.cmd, затем http://localhost:4783. Нужен Node.js 22 или новее. Сервер может уже быть запущен в фоне.

## Как пользоваться

1. Нажмите центральную кнопку и выберите фото или камеру.
2. Нажмите «Определить растение». Фото отправится в OpenAI.
3. Изучите описание и вкладку «Гайд по уходу».
4. Нажмите «Добавить в мой сад». Фото, карточка и уход сохранятся в браузере.

Готовых растений и демопримеров нет. Главная, сад, каталог и уход показывают только добавленные пользователем растения. Прежние демонстрационные записи localStorage больше не используются. Пользовательская коллекция хранится в IndexedDB flowers-user-garden и сохраняется после перезагрузки. При очистке данных браузера она будет удалена. На разных устройствах и адресах сайта коллекции отдельные.

## API

Ключ хранится в .env рядом с server.js (OPENAI_API_KEY). Модель задаёт OPENAI_MODEL, по умолчанию gpt-4.1-mini. Переменные окружения имеют приоритет. После смены ключа перезапустите сервер. .env исключён из Git и не доступен через веб-сервер. Не передавайте папку с заполненным .env другим людям.

Сервер вызывает OpenAI Responses API с изображением и JSON Schema. Генерируются название, семейство, происхождение, особенности, размер, условия и восемь разделов ухода. Если растение не видно или его нельзя определить, предлагается другое фото. Ответ модели — предположение, а не гарантия вида. Запросы требуют доступного баланса OpenAI API.

Фото не записываются сервером на диск; после добавления в сад они хранятся локально в браузере. В OpenAI передаётся store:false. Рекомендации и календарь проверок почвы не заменяют оценку реальной влажности. Push-уведомления не отправляются.

## На телефоне

В одной Wi-Fi сети откройте http://IP-КОМПЬЮТЕРА:4783. Узнайте IPv4 через ipconfig. Может потребоваться разрешение Windows для Node.js в частной сети. Для полноценной установки PWA и публикации нужен HTTPS. Текущая версия предназначена для локального использования, не публичного сервера.

## Файлы

- app.js, index.html, style.css — интерфейс
- storage.js — сохранение в IndexedDB
- server.js — локальный сервер и OpenAI API
- .env — приватный ключ; .env.example — образец без секрета
- assets — изображения и иконка
- start.cmd — запуск

- Фото оформления: https://images.unsplash.com/photo-1501004318641-b39e6451bec6

Распознавание выполняется фоновой задачей локального сервера: интерфейс получает ID сразу и проверяет результат короткими запросами. OpenAI может обрабатываться до 4 минут. Результаты хранятся в памяти сервера до 10 минут; повтор того же фото в этот период не создаёт новый запрос. При перезапуске сервера незавершённые задачи теряются. Проверки: node --test server.test.js.


## Ежедневная забота
Уход показан отдельно для каждого растения. Галочки сохраняются, завершение всех задач запускает анимацию награды. Месячного режима нет. На Vercel используется функция api/index.js с лимитом 300 секунд; ключ OPENAI_API_KEY задаётся только как переменная окружения Vercel. npm run build собирает в public только публичные файлы.
